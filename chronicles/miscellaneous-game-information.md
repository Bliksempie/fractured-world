# Game modes

## The main story line: Last Light

This is the main storyline of the game. It has a distinct end for players who want to experience how their decisions affect the outcome. No single ending is exactly the same. "When hope flickered in a world of ruin."

## The survival story line: Blinding Light

This mode uses the exact same mechanics as the story mode, with the exception that there are no main storyline "quests" for the player, only optional quests that enhances the global world. The player simply enter the global world where chaos reigns, and the world simply moves on. "When survival meant clinging to the embers of what once was."
