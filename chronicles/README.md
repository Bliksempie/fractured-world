# The Chronicles

This folder contains structured lore entries using `show-if` and `fragment-meta` syntax.

Each file represents a core truth (or half-truth) within the Fractured World.

All lore entries use the following metadata format:

<!-- show-if
    discovery: [key]
    state: [discovered|undiscovered]
    confidence: [0–100]
    unlocks: [...]
    tags: [...]
    source-id: [...]
-->

Files here are parse-ready for future dynamic delivery and RAG systems.
