# Narrative

This folder contains the narrative backbone of Fractured World, written in modular acts.

- `mini-novella-act-1.md` — introduction to Elias Holt's descent
- `mini-novella-act-2.md` — fragments of reality unravel further
- All narrative files use a consistent voice and match Cycle 78 lore
- Dialogue and events may reference discoveries from /chronicles

Style: Past tense, present-moment introspection. Clean markdown, no embedded metadata.
