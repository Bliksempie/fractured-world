## Introduction

This novella is personalized for the player using their own character names and gender, and some snippets generated by AI as instructed by the script. When referring to a character, and where applicable, the following applies:

## Personalisation Token Reference

| Token                           | Purpose                                     | Examples                                |
|--------------------------------|---------------------------------------------|-----------------------------------------|
| `{{player}}`                   | Player's chosen name                        | Cameron, Maria                          |
| `{{player-title}}`             | How the child refers to the player          | dad, mom, parent                        |
| `{{player-pronoun}}`           | Player's pronoun                            | he, she, they                           |
| `{{player-pronoun-possessive}}`| Player's possessive pronoun                 | his, her, their                         |
| `{{player-objective}}`         | Player's objective case                     | him, her, them                          |
| `{{player-reflexive}}`         | Player's reflexive pronoun                  | himself, herself, themself              |
| `{{player-descriptor}}`        | Narrative descriptor (with article)         | the man, the woman                      |
| `{{player-descriptor-short}}`  | Narrative descriptor (no article)           | man, woman                              |
| `{{child}}`                    | Child's chosen name                         | Jamie, Emma                             |
| `{{child-pronoun}}`            | Child's pronoun                             | he, she, they                           |
| `{{child-pronoun-possessive}}` | Child's possessive pronoun                  | his, her, their                         |
| `{{child-objective}}`          | Child's objective case                      | him, her, them                          |
| `{{child-reflexive}}`          | Child's reflexive pronoun                   | himself, herself, themself              |
| `{{child-relationship}}`       | Child relationship to player                | son, daughter, child                    |
| `{{child-descriptor}}`         | Narrative descriptor (with article)         | the boy, the girl                       |
| `{{child-descriptor-short}}`   | Narrative descriptor (no article)           | boy, girl                               |
| `{{partner}}`                  | Player's partner label                      | wife, husband, spouse                   |
| `{{partner-title}}`            | Partner role as seen by child               | mom, dad, parent                        |
| `{{partner-pronoun}}`          | Partner's pronoun                           | she, he, they                           |
| `{{partner-possessive}}`       | Partner's possessive pronoun                | her, his, their                         |
| `{{partner-role-relationship}}`| Partner's role to the child                 | mother, father, caregiver               |
| `{{child-pronoun-possessive-cap}}` | Capitalized possessive for child      | His, Her, Their                         |
| `{{player-pronoun-cap}}`       | Capitalized player pronoun                  | He, She, They                           |
| `{{child-descriptor-cap}}`     | Capitalized descriptor                      | Boy, Girl                               |

All attributes are lowercase, except `{{player}}` and `{{child}}`. Everything else is capitalized by adding -cap to it, for example: `{{child-descriptor-cap}}`
